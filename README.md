# PlayPoints

واجهة ويب عربية/إنجليزية بطابع Futuristic UI وHacker Terminal.

## الملفات
- `index.html` — صفحة الدخول والواجهة الرئيسية.
- `weekly.html` — صفحة الجائزة الأسبوعية.
- `tracking.html` — صفحة متابعة الطلب.
- `account.html` — صفحة فحص الحساب.
- `style.css` — التصميم المتجاوب.
- `app.js` — تبديل اللغة والتفاعلات التجريبية.
- `logo.png` و`max.jpg` — صور الهوية، توضعان مباشرة في جذر المستودع.

## تشغيل
افتح `index.html` أو فعّل GitHub Pages من إعدادات المستودع.

## ملاحظة مهمة
هذه نسخة Front-end تجريبية فقط. لا يوجد Backend أو قاعدة بيانات أو تحقق حقيقي من الرموز أو اتصال بأنظمة الحسابات. نموذج الدخول يقبل أي بريد صحيح ورمز غير فارغ لأغراض العرض فقط. لا تجمع أو تدخل كلمات مرور أو بيانات حساسة.

## الصور
أضف ملفي `logo.png` و`max.jpg` مباشرة بجانب `index.html` في جذر المستودع. الصور غير مرفقة تلقائيًا.
